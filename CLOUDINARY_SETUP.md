# Cloudinary Setup (Free Image/Video Upload)

## Step 1 — Create free account
Go to https://cloudinary.com → Sign Up Free (25GB storage free)

## Step 2 — Get credentials
Dashboard → copy these 3 values:
- Cloud Name
- API Key  
- API Secret

## Step 3 — Add to Render backend env vars
| Key | Value |
|---|---|
| CLOUDINARY_CLOUD_NAME | your cloud name |
| CLOUDINARY_API_KEY | your api key |
| CLOUDINARY_API_SECRET | your api secret |

## Done!
Now in Admin Panel → Add Product → you can click
"Choose Image / Video" and upload directly from your phone or PC.
No more copy-pasting URLs!
